Centralized Hub - Provides satellites and their owners a central platform to exchange information and messages
Orbit Path Data Tracking - Keeps access to each others satellite and debris tracking data public to each other
Collision Detection - Analyses the previous data to identify potential intersecting paths and collisions 
Path Adjustment Proposal- Whenever a satellite is at risk of a collision it automatically recommends a path change to be easily accepted by owner
Automated Alerts- Working with the last application module, any anomaly automatically notifies any satellite owner[s] involved, thus cutting response and communication time.
